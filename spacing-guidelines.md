# Spacing Guidelines

All values use a 4px baseline grid for consistent rhythm across devices.

## Tailwind Spacing Scale

Tailwind `--spacer` is set to 0.25rem (4px), each step is times 0.25rem/4px.

| Step | px    | rem     |
| ---- | ----- | ------- |
| 1    | 4px   | 0.25rem |
| 2    | 8px   | 0.5rem  |
| 3    | 12px  | 0.75rem |
| 4    | 16px  | 1rem    |
| 5    | 20px  | 1.25rem |
| 6    | 24px  | 1.5rem  |
| 8    | 32px  | 2rem    |
| 10   | 40px  | 2.5rem  |
| 12   | 48px  | 3rem    |
| 16   | 64px  | 4rem    |
| 20   | 80px  | 5rem    |
| 24   | 96px  | 6rem    |
| 32   | 128px | 8rem    |
| 40   | 160px | 10rem   |
| 44   | 176px | 11rem   |
| 48   | 192px | 12rem   |

## Page & Layout Spacing

| Element                     | Mobile | Tablet | Desktop |
| --------------------------- | ------ | ------ | ------- |
| Page side padding           | 16px   | 24px   | 32px    |
| Section -> Section          | 64px   | 80px   | 96px    |
| Sub-section -> Sub-section  | 48px   | 64px   | 80px    |
| Container inner padding     | 24px   | 32px   | 40px    |
| Section intro -> Content    | 32px   | 40px   | 48px    |
| Form -> Next section        | 48px   | 64px   | 80px    |
| Footer padding (top/bottom) | 32px   | 40px   | 48px    |

## Typography & Text Flow

| Element Relationship    | Mobile | Tablet | Desktop |
| ----------------------- | ------ | ------ | ------- |
| H1 -> Next element      | 32px   | 40px   | 48px    |
| H2 -> Next element      | 24px   | 32px   | 40px    |
| H3/H4 -> Paragraph      | 16px   | 20px   | 24px    |
| Paragraph -> Paragraph  | 12px   | 16px   | 20px    |
| Paragraph -> List/Image | 16px   | 20px   | 24px    |
| List item gap           | 8px    | 12px   | 16px    |
